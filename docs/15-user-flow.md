# User Flow & Journey

This document outlines the typical paths a user takes when interacting with SERA.

## 1. Authentication & Onboarding

- **Landing Page**: Unauthenticated users land on the cinematic intro and product showcase.
- **Auth**: User signs up/logs in via Supabase Auth.
- **Onboarding Flow** (`src/components/onboarding/`):
  - **Welcome**: Introduction to the SERA paradigm.
  - **Persona Step**: Identifying the user's primary role and goals.
  - **Methodology Step**: Choosing a productivity methodology (e.g., GTD, Time Blocking).
  - **Energy Mapping Step**: Defining peak energy hours for smart task scheduling.
  - **Constraints Step**: Defining hard constraints (e.g., working hours).
  - **Completion**: Setting up the database profile.

## 2. The Dashboard Experience

Upon login, the user lands on the **Adaptive Dashboard**:
- **Quick Capture**: A central text/voice input bar to immediately offload thoughts.
- **Today Timeline**: A visual breakdown of the day's scheduled events and timeblocks.
- **Smart Task Queue**: AI-curated list of what to do *right now* based on time and energy levels.
- **Daily Progress Card**: Gamified statistics of daily completions.

## 3. GTD / Task Management

When the user navigates to the Tasks section:
- **Kanban Board**: Tasks are divided into **NOW**, **NEXT**, and **LATER**.
- **Interaction**: Users can drag and drop cards between columns.
- **Detail View**: Clicking a task card opens a dialog to add subtasks, notes, or modify deadlines.

## 4. Voice Interaction Flow

- User clicks the floating Sera FAB (Floating Action Button) or uses a keyboard shortcut.
- The `VoiceOverlay` component activates, capturing browser microphone input.
- User speaks a command.
- The transcript is processed by the `voice-processor` edge function.
- The UI optimistic UI updates immediately, creating a task or navigating to the requested view.

## 5. Analytics & Review

At the end of the day/week:
- User checks the Analytics view.
- Views charts generated by `recharts` showing completion trends.
- `monk-insights` edge function provides an AI-generated summary of productivity bottlenecks and suggestions for the upcoming week.
